# Komentář k vyhlášce č. 259/2012 Sb., o podrobnostech výkonu spisové služby

Otevřený komentář k vyhlášce o podrobnostech výkonu spisové služby — § po §: doslovné znění, výklad, zmocnění a jeho meze, kazuistika, protiargumenty a praktický závěr; příjem, označování a evidence dokumentů, číslo jednací a spis, vyřizování, podepisování a odesílání, spisový a skartační plán, skartační řízení, výstupní datové formáty a jmenný rejstřík.

Konsolidované znění: dokument e-Sbírky `SB-2012-00259_2024-07-01`.
